已改好。保存先写到同目录的临时文件再 rename，失败时原文件不动；换行按原文件保持。

src/main/files.ts · TypeScript复制
export function saveFile(root, file, text, hash) {
  const body = Buffer.from(matchLineEndings(current, text), "utf8");
  writeAtomic(path, body); // 临时文件 + rename
  return { path, hash: sha256(body), size: body.length };
}

边界保留：文件被别人改过即冲突，不覆盖；二进制与超过 1 MB 的文件只读。
