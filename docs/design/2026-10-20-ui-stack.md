# spec.ai.jev 桌面 UI 技术方案

Status: stages 1-5 landed (tokens, chat, small parts, panels, palette)
Date: 2026-10-20

## 0. 结论摘要

| 层 | 选型 | 理由 |
| --- | --- | --- |
| 组件库 | **shadcn/ui + Radix UI**（源码 copy-in），Tailwind 做样式层 | 可控、可改、无版本锁定；token 就是 CSS 变量，能精确贴合 Freebuff 深色 |
| 聊天区 | **assistant-ui**（MIT） | 消息/输入/附件/工具卡/流式/自动滚动是我们手搓最多的一块 |
| 小零件 | `cmdk`、`sonner`、`lucide-react`、`shiki`、`react-resizable-panels` | 各自替掉一段手写逻辑，体积极小 |
| 设计/生成 | `v0`、`Onlook`（探索）；`Penpot` / Figma（出稿） | 只用于页面探索，不进产品依赖 |
| 不采用 | Mantine、Arco、Ant Design 作为主框架 | 会带来另一套默认观感与更大的运行时；Arco 脚手架生成的是后台项目，不是聊天工作台 |

保留自研：`ConversationStore` / `reduceConversation`、`supervisor` / RPC、Board / Files / Judgments 三个产品面板、全部 IPC 与安全边界。

## 1. 现状与约束

- Electron 44 + React 19 + electron-vite；主进程 TypeScript，`app://` 协议 + CSP（`style-src 'self' 'unsafe-inline'`）。
- 渲染层：13 个 tsx、1 个 `styles.css`（约 1,300 行）、手写控件；无图标体系、无代码高亮。
- 质量门禁：239 项单测、68 项 E2E（含 10 项真实 harness）、bundle 预算 571.8 KiB。
- 语言：en / zh / zh-TW；中文排版需要显式处理行高与字重。
- 单机离线：不允许运行时加载远程字体、图标或样式。

## 2. 组件库对比（决策依据）

| 维度 | shadcn/ui + Radix | Mantine | Arco Design | Ant Design |
| --- | --- | --- | --- | --- |
| 形态 | 源码进仓库 | npm 依赖 | npm 依赖 | npm 依赖 |
| 默认观感 | 中性，token 化 | 明显的 Mantine 风格 | 企业后台 | 企业后台 |
| 定制成本 | 低（改自己的代码） | 中（覆盖主题） | 中高 | 高 |
| 体积（按需） | 小（单组件几 KB） | 中 | 大 | 大 |
| 聊天生态 | **assistant-ui 基于它** | 需自适配 | 无 | 无 |
| 升级风险 | 无（自己维护） | 大版本有破坏性变更 | 中 | 中 |

结论：以 shadcn/ui + Radix 为底座。Mantine 只有在"两周内要一套完整表单/通知/命令面板、且接受其观感"时才更优。

## 3. 四层方案

### 3.1 组件库：shadcn/ui + Radix

首批迁入（按"粗糙感"占比排序）：

1. `Button`、`Input`、`Textarea`、`Select`
2. `Tabs`（右侧面板）、`Dialog`、`DropdownMenu`、`Tooltip`
3. `Switch`、`Badge`、`Separator`、`ScrollArea`
4. `Command`（由 cmdk 提供）、`Toast`（由 sonner 提供）

Token 映射（Freebuff → shadcn 变量）：

| 语义 | 现值 | shadcn 变量 |
| --- | --- | --- |
| 页面底色 | `#0d0f12` | `--background` |
| 主文字 | `#f1f5f9` | `--foreground` |
| 主色 | `#9efc62` | `--primary` |
| 面板 | `#1c1f24` | `--card` |
| 次面板 | `#242930` | `--secondary` / `--muted` |
| 边框 | `#2c333d` | `--border` |
| 代码块 | `#374151` | `--code`（自定义） |
| 行内代码 | `#ff8534` | `--code-inline`（自定义） |
| 标题 | `#facc15` | `--heading`（自定义） |

目录：`src/renderer/ui/*`（copy-in），样式只引用 token，不直接写色值。

### 3.2 聊天区：assistant-ui

- 替换：`Thread`、`Message`、`Composer`、附件、工具调用卡片、流式渲染、自动滚动。
- 保留：`ConversationStore` 与 `reduceConversation`（事件折叠是我们自己的语义）；`assistant-ui` 只做视图与输入。
- 适配层：把现有 `AgentEvent` 流包成一个 runtime adapter；附件继续走 `PromptImage`（PNG/JPEG/WebP/GIF、6 张、5 MB）；工具卡用 `ToolFallback` 自定义成当前样式。
- 风险：React 19 兼容、CSP（内联样式已允许）、流式事件形状差异；先做一个分支 spike 验证。

### 3.3 小零件

| 零件 | 替掉 | 体积 | 许可 |
| --- | --- | --- | --- |
| `cmdk` | 手写 QuickOpen 的过滤/键盘 | ~10 KB | MIT |
| `sonner` | 手写 error banner / 状态提示 | ~8 KB | MIT |
| `lucide-react` | 纯文字按钮，无图标 | 按需 tree-shake | ISC |
| `shiki` | 裸 `<pre>` 代码块 | ~50 KB（常用语言） | MIT |
| `react-resizable-panels` | 固定三栏 | ~12 KB | MIT |
| `@radix-ui/react-*` | 弹层/菜单/提示的可访问实现 | 按需 | MIT |

### 3.4 设计与生成工具

| 工具 | 用途 | 边界 |
| --- | --- | --- |
| `v0`（Vercel） | 提示词生成 shadcn 页面，直接出可粘贴代码 | 闭源 SaaS；产出需人工收敛 |
| `Onlook` | 开源 React+Tailwind 可视化编辑（Apache-2.0） | 适合改现有页面，不适合整壳 |
| `Penpot` | 开源设计稿（MPL-2.0） | 只出稿，不产代码 |
| Figma + Anima/Locofy | 设计稿转代码 | 样式需重写，质量参差 |

### 3.5 视觉方向（本次 HTML 原型）

同一套布局与内容，提供三个可切换方向：

| 方向 | 气质 | 关键 token |
| --- | --- | --- |
| **A · Studio（推荐）** | 工作室感，留白、圆润、克制 | 暖炭黑 `#141518`，lime `#9efc62`，圆角 18/14/10，正文 14.5px |
| **B · Terminal** | 开发者工具，紧凑、等宽、硬边 | 近黑 `#0a0b0d`，lime 细线，圆角 6/4，标签等宽，正文 12.5px |
| **C · Editorial** | 编辑室，衬线标题、暖色、非对称 | 深墨 `#12100e`，琥珀 `#f5c451` + lime 次色，圆角 12，标题衬线 |

## 4. 迁移计划

| 阶段 | 内容 | 验收 |
| --- | --- | --- |
| 0 | 技术 spike：Tailwind + shadcn + assistant-ui 的最小页面 | 截图 + 体积 + 启动时间 |
| 1 | Token 与基础控件替换 | 三屏截图一致；E2E 通过；体积 ≤ +80 KiB |
| 2 | 聊天区替换（assistant-ui） | 消息/流式/附件/工具卡四条 E2E 通过 |
| 3 | 小零件替换（cmdk/sonner/lucide/shiki/panels） | 命令面板、错误提示、代码高亮各一条 E2E |
| 4 | 面板重绘（Board/Files/Judgments） | 截图回归 + 键盘/读屏检查 |
| 5 | 清理旧 CSS，更新预算与文档 | bundle 记录、README、release 说明 |

每一步单独提交，可回滚。

### 阶段 1 记录（2026-10-20）

- Tailwind 4 + shadcn/Radix 基础控件已进入 `src/renderer/ui/`；旧的 `styles.css` 被放进 `legacy` 级联层，Tailwind utilities 可以逐件覆盖。
- 已替换：App 侧栏按钮/搜索/模型选择、Composer、ApprovalCard、FirstRun、Settings 的语言/模型/更新控件。
- 实测：renderer JS 429.9 KiB，CSS 34.2 KiB，总计 704.6 KiB；预算文件已按实测值更新。
- 未替换：Conversation 消息流、三个产品面板、manifest 的复杂设置控件（留给阶段 2/4）。

### 阶段 2 spike 记录（2026-10-20）

- `AssistantThread.tsx` 已接入 `@assistant-ui/core` 的外部 store runtime、消息模型和消息列表 hook；`ConversationStore` 仍是唯一数据源。
- 消息、工具行、流式光标和自动滚动由 assistant-ui 的消息状态驱动；Composer 已由 `ComposerPrimitive` 接管，附件走 `SimpleImageAttachmentAdapter` 包装校验。
- 停止按钮仍由产品状态控制，因为“harness 在运行就可以停止”比 assistant-ui 的“当前 turn 可取消”更符合现有行为。
- 代价：renderer JS 758.0 KiB，其中主包 430.5 KiB、assistant-ui 懒加载分包 345.6 KiB（两者 gzip 合计约 234.5 KiB），总计 1032.9 KiB。
- 结论：交互和 19 项对话/GUI E2E 通过，可以继续；如果后续体积不可接受，回退点是 `AssistantThread.tsx` 一个文件。

### 阶段 3 记录（2026-10-20）

- 工具行已由 `MessagePrimitive.Parts` 的 `tools.Override` + `ToolFallback` 渲染，`AssistantThread` 不再手写工具卡片。
- 删除 composer 时代留下的旧 CSS（约 2.8 KiB），包括拖动提示、旧附件、旧侧栏按钮和原生 select 规则。
- manifest 的 boolean/number/text/list/numbers/choice 控件改用 Switch/Input/Textarea/Radix Select；面板标签改用 Radix Tabs。
- Board / Files / Judgments 三个面板改用统一的 Button/Badge/Textarea 和语义 token；文件编辑、diff、判决复制保持原行为。
- 实测：renderer JS 793.0 KiB（gzip 约 244.9 KiB），CSS 33.3 KiB，总计 1066.8 KiB；完整 E2E 56 passed / 12 skipped / 0 failed。

### 阶段 4 记录（2026-10-20）

- Quick open 改用 cmdk，服务端排序不变，键盘选择、回车和 Escape 由 cmdk 接管。
- 错误横幅改为 sonner toast；错误仍带 `data-testid="error"`，并且持续到关闭。
- 代码块改用 Shiki 的 token 输出，由 React span 渲染而不是 HTML 字符串；当前按需加载 TypeScript、TSX、JSON、Bash、Python、Diff。
- workspace 从固定 grid 改成 react-resizable-panels 的 Group/Panel/Separator，右侧面板可拖拽。
- 实测：renderer JS 1524.6 KiB（含按需加载的 Shiki 语法包；gzip 约 378.9 KiB），CSS 47.1 KiB，总计 1812.2 KiB；完整 E2E 56 passed / 12 skipped / 0 failed。

### 阶段 5 记录（2026-10-20）
- Quick open 扩成命令面板：`Ctrl+P` / `Ctrl+K` 同一个入口；文件来自主进程搜索，会话与动作在渲染层过滤，`cmdk` 只管键盘与回车。当前打开的会话不会在“会话”组里重复出现。
- 动作：新建任务、打开工作区、设置、重启 agent、隐藏/显示右侧面板。
- 右侧面板改用 v4 的 collapsible Panel（`collapse()` / `expand()`）：对话区占满整行，展开回到折叠前的宽度，输入框草稿不丢；折叠状态写入 `localStorage`（`spec.ai.jev.panelsOpen`），重启后恢复。拖拽后的比例本身仍不跨重启保存（v4 没有 `autoSaveId`）。
- 三语文案补齐；新增 E2E：`Ctrl+K` 执行动作、跨项目会话搜索、面板折叠与状态写入。
- 实测：renderer JS 1528.5 KiB（gzip 约 380 KiB），CSS 46.9 KiB；完整 E2E 59 passed / 12 skipped / 0 failed（新增 3 条）。

### 阶段 6 记录（2026-10-20）
- `Ctrl+B` 折叠/展开右侧面板；命令面板里的同一动作带快捷键提示。分隔条拖到最小也会折叠，标题栏和面板状态随之同步。
- 分栏比例改用 `useDefaultLayout`（`onlySaveAfterUserInteractions`）保存，重启后恢复；折叠状态（布尔）与分栏比例分开存储，互不覆盖。
- 命令面板底部加入 `↑↓ / Enter / Esc` 操作提示。
- 实测：renderer JS 1530.8 KiB，CSS 47.1 KiB，总计 1818.4 KiB；完整 E2E 61 passed / 12 skipped / 0 failed（新增 2 条）。

### 阶段 7 记录（2026-10-20）
- 快捷键补齐：`Ctrl+N` 新建任务、`Ctrl+O` 打开项目、`Ctrl+,` 设置、`Ctrl+B` 折叠面板；命令面板的动作行显示对应按键（macOS 显示 `⌘`）。
- 命令面板按最近使用排序（`spec.ai.jev.paletteRecent`，最多 6 条），只调整组内顺序，不改变“动作 / 会话 / 文件”的分组。
- 右侧面板记住上次打开的标签页（`spec.ai.jev.panelTab`），重启后回到 Board / Files / Judgments 中的同一个。
- 实测：renderer JS 1531.8 KiB，CSS 47.1 KiB，总计 1819.4 KiB；单测 245 passed，完整 E2E 63 passed / 12 skipped / 0 failed。

## 5. 体积与性能

- 预估：Tailwind 输出 + shadcn/Radix 按需 ≈ +30–80 KiB；`assistant-ui` 另计（以 spike 实测为准）。
- 预算策略：先量后调；renderer JS 预算从 295.6 KiB 提到实测值 + 5%，CSS 同理。
- 启动：保持 `electronDist` 本地打包、3 个 locale、asar；新增依赖只进 renderer，不进主进程。

## 6. 风险与对策

| 风险 | 对策 |
| --- | --- |
| Tailwind 迁移期间样式双轨 | 每个组件迁完即删旧 CSS，禁止长期并存 |
| assistant-ui 事件模型不匹配 | 先做 adapter spike，保留旧视图作为回退 |
| E2E 选择器失效 | 全部交互保留 `data-testid`，迁移时先跑回归 |
| 体积膨胀 | 每阶段记录 budget，超出即审查 |
| 许可证 | 全部 MIT/Apache/ISC；copy-in 组件保留来源说明 |

## 7. 验收标准

1. 三个核心屏（对话、文件、判决）在 1180×780 与 720×540 下无溢出、无截断。
2. 68 项 E2E 全绿；新增组件各自至少一条交互测试。
3. bundle 记录在案；CSP 无违规；无远程资源。
4. 中文界面无英文残留（状态栏、看板、会话卡、更新提示）。
5. 视觉方向经确认后冻结 token，再进入实现。
